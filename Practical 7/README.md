1. What are the different types of expressions?
●	There are three types of expressions based on the position of operators.
●	They are:
1.	Infix expression
2.	Prefix expression
3.	Postfix expression
2. Give examples of all types of expressions.
●	Infix: a + b — operator is written between operands.
●	Prefix: + a b — operator is written before operands.
●	Postfix: a b + — operator is written after operands.
3. Which data structure is used for evaluation of expression?
●	Stack is used for the evaluation of expressions.
●	Stack follows the LIFO (Last In, First Out) principle.
●	It is commonly used for postfix and prefix expression evaluation.
4. Convert infix expression a+b+c+d to prefix expression.
●	Infix expression: a + b + c + d
●	Prefix expression: +++abcd
●	Here, the operators are placed before the operands.
5. Convert infix expression a+b+c+d to postfix expression.
●	Infix expression: a + b + c + d
●	Postfix expression: ab+c+d+
●	Here, the operators are placed after the operands.
