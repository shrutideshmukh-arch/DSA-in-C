1. What is a tree?
Ans: A tree is a nonlinear data structure used for hierarchical data management.
2. What is a binary tree?
Ans: A binary tree is a tree in which each node has at most two children, called the left child and the right child.
3. What are the types of binary trees?
Ans: Complete binary tree, full binary tree, binary search tree, skewed binary tree, and threaded binary tree.
4. What are the tree traversal techniques?
Ans: 1) Recursive 2) Non-recursive
5. What are the recursive tree traversal techniques?
Ans: 1) Inorder 2) Preorder 3) Postorder
6. What is an AVL tree?
Ans: An AVL tree is a height-balanced binary search tree.
7. What are the basic operations that can be performed on a tree?
Ans: 1) Creation 2) Insertion 3) Deletion 4) Searching 5) Traversal
8. Explain the terms degree and height of a tree.
Ans:
	Degree of a node: The number of children of a node is called its degree.
	Height of a tree: The maximum number of edges in the longest path from the root to a leaf.
9. Draw the representation of a tree using a linked list and an array.
Ans:
(a) Array Representation: Nodes are stored in an array. For a binary tree using 1-based indexing, the left child of a node at index i is at 2i, and the right child is at 2i+1.
(b) Linked List Representation: Each node consists of three fields: left pointer, data, and right pointer. The pointers store the addresses of the left and right child nodes. If a child does not exist, the corresponding pointer is NULL.
